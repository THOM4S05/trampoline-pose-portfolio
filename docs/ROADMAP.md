# Roadmap

This is an actively developed experimental project. Completed work is recorded
in Git commits; this list describes intended work, not promised accuracy.

- [x] Offline pose export with native timestamps and explicit missing values.
- [x] Athlete selection, bidirectional association and conservative reacquisition.
- [x] Private browser upload, processing queue and downloadable review outputs.
- [x] Experimental contact, rotation and body-shape evidence.
- [x] Automated tests and a synthetic demo requiring no GPU.
- [ ] Verify full GPU setup on a clean second Windows machine.
- [x] Prepare the owner's selected RedTuckBacks real-video demonstration.
- [ ] Build an independent labelled evaluation set.
- [ ] Measure difficult-pose error, side swaps and identity switches.
- [ ] Evaluate improved detection and appearance features on held-out routines.
